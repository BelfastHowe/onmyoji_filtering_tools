# 御魂账号库

![银发龙女微笑着问「老实选号，很枯燥吧！」](docs/readme-cover.png)

在本地批量比较阴阳师藏宝阁账号。导入一批 JSON 后，可以按一速、须佐之男 21 项平均分或阵容达标情况筛选账号，再点进结果查看对应的六件御魂。

将藏宝阁 JSON 放入 `account_data`，双击 **启动账号库.cmd**，在首页点击「添加账号并计算」。以后把新 JSON 放进同一目录，再点一次即可。Git 只跟踪目录占位文件。网页默认使用 `http://127.0.0.1:4317/`。启动器可使用 PATH 中的 Node 或 Codex 自带的 Node 24。首次从源码运行时先执行下面的构建命令。

## 开发和命令行

需要 Node.js 24+、pnpm。依赖安装和前端构建只在首次安装或更新代码时需要。账号处理期间只访问本机。

```powershell
pnpm install --frozen-lockfile
pnpm run build
node app/installRules.ts
node app/import.ts
node app/server.ts
```

运行 `node --test "tests/*.test.*"` 验证导出器、更新与去重、独立批次、满速和六件套查询。可通过 `CBG_PORT` 指定服务端口，启动器默认使用 4317。

## 当前功能

- 增量扫描、逐文件错误报告、按商品和有效角色 ID 去重、库存快照、历史批次。SQLite 数据库位于 `local_data/accounts.sqlite`，包含压缩的原始响应、标准化御魂和已计算结果。备份时关闭服务，或使用 SQLite 在线备份。
- 跨账号搜索支持多个指标范围、阵容模板任一或全部达标、主排序及两级次排序。缺少结果的账号排在有分账号之后。首页默认按散件一速降序显示。
- 散件一至五速、散件命中一至三速、散件抵抗一至二速、库存套装四件一速及指定套装命中一速。每项保存六个 UUID；缺少满足要求的六件时保留空值。阶次之间排除上一阶使用过的御魂。
- PVE 预览实现 26 个单式神预设。须佐之男使用七种四件套分别搭配土蜘蛛、荒骷髅和鬼灵歌伎；另有魂土天照、超星玉藻前、因幡辉夜姬散件/火灵和不见岳散件。攻击型预设在满足速度和满暴条件后，以攻击 × 暴伤作为面板指标。辅助预设分别取暴伤百分比或防御。指标可跨账号筛选、排序并查看六件明细。
- 套装库存、六个位置的最高副属性与满速件数；可按位置和套装翻阅单件御魂、固有属性和输出等七个指标。百分比副属性以百分点显示。

在「一速预览」或「PVE 预览」里选中配装，左上角为一号位，沿逆时针依次为二至六号位。点击图标可查看主副属性、强化次数、固有属性和套装效果。按 Esc 返回当前配装。带式神的预设会在图下显示八项御魂加成，按预设式神的基础面板折算攻击、生命和防御。

套装图标已保存在 `web/public/souls`，可离线使用。图标和式神基础面板取自[痒痒鼠魔方](https://yyshub.top/#/yuhun/score)，套装效果来自[网易藏宝阁游戏配置](https://cbg-yys.res.netease.com/js/game_auto_config.js)。

六件套速度在六星 +15 候选中按二号速度主属性求解，四件套检查六个位置中所有四位选择。原始副属性系数与展示值舍入一致时采用系数精度，特殊固定御魂使用实际展示值。速度并列时按 UUID 稳定选件，可能与参考网站选择不同的同速御魂。

## 阵容和 PVE

首次安装时，`installRules.ts` 下载并校验固定版本的魔方公开规则。缓存位于 `local_data/rules`。之后的导入、计算、筛选和查看均可离线完成。

**升级计算规则时**，先确认要重算的账号原始 JSON 都在 `account_data`，安装新规则并启动新版服务。在首页点击「清空数据库」并确认，再点「添加账号并计算」。清库会移除旧批次和计算结果。

添加账号时计算基础分析和 PVE。需要阵容时，在首页「一键预设 · 手动批量计算」选择模式并点击「计算全部当前账号」，或在账号详情的「一键预设」中点击「计算当前账号」。每次只提交所选范围、所选模式的缺失模板，已完成的配装可直接复用。四种模式各包含六个场景、24 个模板。首页可以暂停所选模式。当前数据范围内所有账号完成任一模式后，即可在阵容下拉菜单搜索和多选该模式的模板。后续追加账号可手动补算。基础分析、快速 PVE 和阵容任务使用系统允许的逻辑线程，实际并发按待算任务和可用内存调整。命令行可用 `node app/calcTeams.ts 严格快速`。每个账号的「一键预设」保留成员、实际选用的六件、面板、缺少的式神及模板条件。纯挂件按模板展示套装要求。

「PVE 预览」默认展示魔方快速模式，可切换本地最优。两种模式各自保留 26 项指标和配装，分别计算「须佐之男 · 21项平均分」。七种四件套与三种首领的 21 个面板值等权，配不出的组合计 0，全部算完后入库，可在主页按均分筛选或排序。已有快照在新版服务打开数据库时自动补齐均分。跨账号排行还可选择快速模式下七种四件套的三首领均值。

## 账号详情

从账号排行进入详情，顶部可切换六个页面。点击「紧凑显示」可缩小菜单和图表的间距，设置会保存在当前浏览器中。

| 页面 | 可查看的数据 |
| --- | --- |
| 一键预设 | 按副本、计算模式和达标状态查看模板，展开成员后可查看配装。 |
| 御魂列表 | 按套装、位置、主属性、固有属性和单件指标筛选排序。点击御魂查看完整属性；选择收益次数时可展开收益统计。 |
| 一速预览 | 分组查看散件、命中、抵抗和套装速度。点击已配出的方案可查看六件御魂。 |
| PVE 预览 | 比较首领搭配、平均值和其他预设指标，可切换快速与本地最优模式。 |
| 套装多维度雷达图 | 选择副属性，并排比较各套装六个位置的最高值，或切换明细表。 |
| 套装满速分布情况 | 按满速总数降序排列，六种颜色分别表示一至六号位的件数，明细表显示各位置的精确值。 |

「一键预设」中的「达标」表示配装满足模板条件。详情单独显示式神是否齐全，技能要求供查阅。某个账号在所选模式下完成一个副本的全部模板后，排行才显示该副本的达标模板数，此前显示「未计算」。

本地阵容伤害按套装件数启用增伤。两件心眼提供 15% 攻击加成，至少四件才会按目标已损失的生命计算增伤。模板未提供血量时，心眼的残血增伤按零计。旧库升级时，可能受此修正影响的阵容会标为「已暂停」，可在原模式下手动补算。

本次移除单件评分的数据库结构更新会在首次启动时自动迁移。同一计算规则版本下的历史批次、一速、PVE 和阵容结果可继续查看。

## 可选的离线结果对照

导入原始账号后，运行 `node app/compareReference.ts account_data` 将同一快照的一速、快速 PVE 指标和六件 UUID 与魔方参考库存的计算结果对照。目录模式读取 `ref-*.json`；也可以传单份参考文件。加 `--original` 会使用未经加速修改的魔方计算线程。已有参考文件仅供这条对照命令使用。

如需生成新的参考文件，显式运行 `node app/fetchReference.ts <账号文件>` 会将该文件上传至魔方，在原目录保存 `ref-<原文件哈希>.json`。日常导入和计算只需要藏宝阁原始 JSON。

设计和验收记录见[批量计算与账号筛选设计](docs/批量计算与账号筛选设计.md)。
